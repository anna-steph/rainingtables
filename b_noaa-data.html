Appendix B — NOAA Precipitation Data

In rainingtables, we’re pulling data from the NOAA Global Historical Climatology Network Daily (GHCNd). Let’s take a look and review NOAA’s notes on these data to understand what we’re working with.

As NOAA explains, the GHCNd is an integrated database of daily climate summaries from more than 100,000 weather stations across 180 countries and territories worldwide. In addition to data on total precipitation, summaries provide minimum and maximum temperature, snowfall, and snow depth.

Weather stations vary in (a) how many fields and observations they provide and (b) how long they’ve been operational:

  1. Not all weather stations report all data fields. About half of stations only report precipitation.
  2. Stations don’t necessarily start reporting data on the same day. Some stations have reported data for less than a year, some more than 175 years. Some previously reported data but have since ceased operating.

Mind Your Metadata

With clean, accessible, and detailed data like NOAA’s, you may be tempted to jump into analysis and overlook key metadata and data exploration. Resist! Some metadata fields contain user notes from our nice NOAA nerds. They want you to know what you’re looking at.

🌂

As an example, let’s pick iconic places in a few rainy cities to pull data from:

Rainy City Iconic Place Zip Code
Syracuse, NY Erie Canal Museum 13202
Portland, OR Rose Garden in Washington Park 97205
Grand Rapids, MI Grand Rapids Public Museum 49504

Let’s use their zipcodes to pull their precipitation data and walk through it.

# pull data for these zipcodes
zipcodes <- c("13202", "97205", "49504")

# not all zipcodes have a weather station in them
# safe_pull allows the function to continue if it returns a null result on one zipcode
safe_pull <- purrr::safely(pull_daily_rain)

# pulling data from the past three months
rain_list <- purrr::map(zipcodes, function(z) {
  safe_pull(
    api_key = Sys.getenv("NOAA_CDO_KEY"),
    zipcode = z,
    date_start = Sys.Date() - months(3),
    date_end = Sys.Date()
  )
}) |> purrr::set_names(zipcodes)

example_table <- rain_list |>
    purrr::map("result") |>
    purrr::compact() |>
    purrr::imap_dfr(function(df, zip) {
        df |>
            mutate(zipcode = zip)
    }) |>
    bind_rows()

See Column 4, attributes? These are data notes from NOAA. They help us understand what we’re seeing if we can crack the code. How can we interpret attributes? Look at the attributes values in zipcode 49504 observations. How do we find out what “N” means?

The answer: it takes a bit of fishing on NOAA’s website. 🎣

🐟 Fish 1: metadata manuals.

Most public data sources have at least one metadata manual available to help you interpret their data. NOAA’s no exception:

  • When we look at NOAA’s Climate Data Online Dataset Discovery page, we see a link to NOAA’s GHCN Documentation.
  • Scroll down to page 3, and under Table 2 (Quality Flag/Attribute), we see: “N = failed naught check”.

Okay, what is a naught check? 🧐

🐠 Fish 2: more metadata mining.

  • With a bit more fishing, we find a second webpage, Global Historical Climatology Network - Daily (GHCN - Daily), Version 3. On this page, we spot a GHCNd README File, open it, and scroll down. Again we see “N = failed naught check” under QFLAG1, “the quality flag for the first day of the month.”

Let’s align this with what we see in NOAA’s GHCN Documentation, which you can find reviewing their Climate Data Online Dataset Discovery page.

Their notes on daily summaries, with additional documentation here:

NoteDaily Summaries

Global Historical Climate Network includes daily land surface observations from around the world. The GHCNd was developed to meet the needs of climate analysis and monitoring studies that require data at a sub-monthly time resolution (e.g., assessments of the frequency of heavy rainfall, heat wave duration, etc.). The dataset includes observations from World Meteorological Organization, Cooperative, and CoCoRaHS networks. If observed, the station dataset includes max and minimum temperatures, total precipitation, snowfall, and depth of snow on ground. Some U.S. station data are typically delayed only 24 hours.

Since NOAA has a number of weather stations, with varying periods of observation, we can also search our city names using their Climate Data Online Search.

  • If we view the details of Grand Rapids, we learn NOAA has 87 weather stations in this area, but only a handful have 100% coverage through the current date.

max_rain <- rain_list |>
    purrr::map("result") |>
    purrr::compact() |>
    purrr::imap_dfr(function(df, zip) {
        df |>
            filter(value == max(value, na.rm = FALSE)) |>
            mutate(zipcode = zip) |>
            mutate(date_format = as.Date(stringr::str_extract(date, ".+(?=T)"), "%Y-%m-%d")
            )
})
