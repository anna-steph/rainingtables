# What's 🌧️ Raining Tables 🌧️ ?

🌧️ Raining Tables 🌧️ is a learning package. 

Many analysts can write scripts using Python or R but might be unsure how to move their analytical scripts into "production," usually some kind of automated, recurring data workflow. This package aims to give early programmers exposure to analytical pipelines by building one in incremental steps. 

Using [daily precipitation data from NOAA](https://www.ncei.noaa.gov/cdo-web/search?datasetid=GHCND), 🌧️ Raining Tables 🌧️ helps analysts:  

- read in an Excel table,
- pull data updates from APIs,
- explore report templates (parameterized reports),
- read out to databases,
- create a simple dashboard,
- ensure reproducibility,
- save to Google Drive,
- put our programs in a container, and 
- run our container on a cloud platform. 

By walking through these steps, this package aims to help you understand your script as part of an automated analytical pipeline, one that might flow from: 

    Public data APIs > Report templates > Databases
                                        > APIs > Dashboards
                                        > Excel/PDFs/other outputs > Google Drive
                                        > Containers > Cloud
